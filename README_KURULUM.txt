MAVİ FIRIN - 10 HAFTALIK SEO DERSİ ÖRNEK WEB SİTESİ

1) index.html dosyasını çift tıklayıp tarayıcıda açın.
2) VS Code ile HTML ve CSS dosyalarını düzenleyin.
3) Yayın için GitHub Pages veya benzeri HTTPS barındırma kullanın.
4) Search Console doğrulama ve GA4 için yayınlanmış gerçek URL gereklidir.
5) sitemap-ORNEK.xml içindeki ORNEK-ADRES alanını yayın alan adınızla değiştirip sitemap.xml adıyla yayınlayın.
6) GA4'ün sağladığı GERÇEK Google etiketini her sayfanın <head> içine yerleştirin.
7) Bütün işletme bilgileri kurgusaldır; iletişim formu veri göndermez.
8) Gerçek veri toplamak için gizlilik ve çerez/onay yükümlülüklerini ayrıca değerlendirin.
